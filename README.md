# Deskmerit

Automatic Time Tracking & Workforce Insights for Teams.

Deskmerit is the automatic time tracking software modern teams trust. Integrates directly with Jira, Azure DevOps, and HRMS platforms to track attendance and billable hours without invasive keystroke logging.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
